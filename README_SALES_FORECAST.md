# ИИ-прогноз продаж — простое описание

## Что делает

В админ-панели кнопка **«ИИ-прогноз продаж»** открывает окно, которое показывает:

- сколько пластинок примерно продадут в следующем месяце;
- какую выручку ожидает модель;
- график продаж и таблицы по годам, месяцам и дням.

Доступ есть только у администратора. Все продажи вымышленные: реальные заказы, цены и остатки магазина не меняются.

## Как работает по шагам

1. Администратор открывает окно прогноза.
2. Java проверяет права и отправляет запрос Python-сервису.
3. Python создаёт историю продаж за 36 завершённых месяцев: количество пластинок и среднюю цену за каждый день.
4. Модель учится находить в этой истории сезонность, изменения спроса по дням недели и общий рост продаж.
5. Предсказывает количество и среднюю цену на каждый будущий день.
6. Считает выручку: **количество × средняя цена**. Затем складывает дневные значения в месяцы и годы.
7. Результат возвращается в окно админ-панели.

```text
Админ-панель → Java → Python → прогноз → админ-панель
```

## Как обучается

Используется небольшая нейросеть **ELM с 24 скрытыми нейронами** на Python и NumPy. Скрытый слой фиксирован, а выходные веса рассчитываются по примерам продаж. Это отдельная модель от рекомендаций пластинок на главной.

Сначала последние **90 дней** истории откладываются для проверки. Модель обучается на более ранних днях, предсказывает отложенные и сравнивает результат с вымышленными продажами. В окне показана **MAE — средняя ошибка за день**: чем она меньше, тем точнее прогноз на этих примерах.

После проверки модель обучается на всей истории и рассчитывает будущее. Реальные покупки пользователей в обучение не добавляются.

## На какой срок строится прогноз

Прогноз охватывает **текущий месяц целиком и следующие 12 месяцев**. Следующий месяц отдельно выделен в верхних карточках. Годовые суммы включают только дни этого диапазона — число учтённых дней видно в таблице.

Результат сохраняется в памяти Python. Повторное открытие в том же месяце использует готовый расчёт. Новый месяц или перезапуск сервиса приводит к новому расчёту при следующем запросе.

## Где открыть и где находится код

- Открыть: **http://localhost:8080/admin?forecast=1** под администратором.
- [recommender/forecast.py](recommender/forecast.py) — данные, обучение и прогноз.
- [SalesForecastController.java](backend/src/main/java/ru/mirea/vinylstore/recommendation/SalesForecastController.java) — проверка доступа и связь с Python.
- [SalesForecast.jsx](frontend/src/features/admin/SalesForecast.jsx) — окно с графиком и таблицами.

Python запускается вместе с магазином через Docker Compose. Если он недоступен, окно показывает ошибку и кнопку повтора; остальной магазин продолжает работать.

**Важно:** это учебный прогноз на синтетических данных, а не гарантия реальных продаж. Выручка не равна прибыли — расходы здесь не учитываются.
