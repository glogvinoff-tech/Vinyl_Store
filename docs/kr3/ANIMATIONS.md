# Фронтенд и анимации версии 2.1

Источник текущего фронтенда — предоставленная папка `VINYL_STORE-version_2.1`. Компоненты React и основной CSS перенесены в `frontend/src/`, изображения, шрифты и аудио — в `frontend/public/`. Python backend исходника заменён подключением к существующему Spring Boot REST API.

## Эффекты

- `components/SpinningRecord.jsx`: автоматическое вращение 7 градусов/с, перетаскивание Pointer Events, ограниченная инерция с затуханием, пауза, управление стрелками/Home/End и ARIA slider. Автоматическое движение отключается при `prefers-reduced-motion` и в скрытой вкладке.
- `components/Radio.jsx`: реальное воспроизведение шести локальных аудиофайлов, выбор/переключение трека, пауза, прогресс, вращение пластинки по позиции воспроизведения и перемотка перетаскиванием. Один оборот соответствует 30 секундам трека.
- `styles/spin.css`: увеличение обложки, подъём кнопок и жанров, heart-pop/heart-ring для избранного, cart-bump для корзины, последовательное появление карточек card-in, плавные уведомления и прокрутка.
- `components/Design.jsx`: исходные SVG с сохранением пропорций, ResizeObserver для адаптивного масштаба, отдельные эффекты обновления счётчиков.
- `features/auth/AuthModal.jsx`: оформление почтовой авторизации из версии 2.1; отправка и проверка кода, повторная отправка с таймером, вход по паролю и смена временного пароля используют API КР №3.

Шрифты Stinger Fit Heavy/Bold и Inter 400/500/600/700 загружаются локально. Дополнительной библиотеки анимаций нет: CSS, requestAnimationFrame и браузерные события.

## Сборка

`npm ci --prefix frontend`, затем `node scripts/build-frontend.mjs`. При запуске Docker обе части автоматически собирает `backend/Dockerfile` из корня проекта. Редактировать нужно `frontend/src/styles/spin.css`, а не сгенерированный CSS в `static/frontend-assets/`.

Первый перенос небольших эффектов из GitHub MarioDD1/VINYL_STORE (commit `835d4470423787efa1684c2affabb936c1479d74`) заменён полным фронтендом локальной версии 2.1.
