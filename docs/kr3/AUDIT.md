## Найденные и исправленные дефекты

### 1. Исправлена обработка повреждённого CSV

До исправления: `POST /api/orders/import/preview`, multipart-файл с корректным заголовком и незакрытой кавычкой в следующей строке возвращал HTTP 500, `INTERNAL_ERROR`. Требовался HTTP 400 с понятным сообщением о структуре CSV.

Место: `backend/src/main/java/ru/mirea/vinylstore/service/CsvStoreOrderService.java`, `parse()`, строки 175–209. Ошибка чтения возникает при обходе итератора, за пределами внутреннего `try`; внешний обработчик не охватывает `UncheckedIOException`.

Исправлено: обработаны `IOException` и `UncheckedIOException`, API возвращает 400 с безопасным сообщением. Регрессионный тест проверяет preview/apply в обоих режимах: перед повреждённой строкой стоит корректная, но ни одна запись не создаётся.

### 2. Исправлено сохранение события экспорта CSV

До исправления: `GET /api/orders/export?q=record:<код тестовой пластинки>` скачивал файл, но проверка PostgreSQL показывала **0** событий `ORDER_CSV_EXPORTED` для тестового администратора.

Исправлено в том же сервисе, `export()`: транзакция допускает запись аудита после формирования файла. Общая транзакционная модель AuditService сохранена. Регрессионный тест проверяет сохранение ровно одного события с автором, фильтром и correlation ID.

Раздел 11 реализован для входов и изменения данных; дефект касается дополнительного события экспорта. Экспорт не является изменением данных, поэтому это замечание к корректности заявленной реализации аудита, а не отсутствие всего обязательного раздела.
